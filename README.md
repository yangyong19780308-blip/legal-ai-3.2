# ⚖ 法务AI 3.2 · 基层治理版

一个手机、电脑都能用的法律文书与纠纷处理工具。全部功能集中在一个文件里，打开即用，无需安装、无需服务器，数据（案件、密钥、费用台账）只保存在你自己的浏览器里。

## 在线使用地址

开通 GitHub Pages 后，用手机或电脑浏览器打开：

`https://yangyong19780308-blip.github.io/legal-ai-3.2/`

## 功能模块

| 模块 | 说明 |
| --- | --- |
| 📁 案件台 | 案件档案：新建、保存、打开、删除，文书可一键存入案件 |
| 📝 材料撰写 | 起诉状（一律成对生成要素式＋传统式两份）、答辩状、强制执行申请书（要素式）、信访材料、变更诉讼请求、其他文书；覆盖最高法 67 类要素式案由 |
| 🧾 证据分析 | 粘贴案情和证据，AI 生成证据清单、质证意见、补证建议、风险提示 |
| 📚 法律研究 | 输入法律问题，AI 引用法规分点作答，附常用问题快捷入口 |
| 🗺 诉讼流程 | 民事一审流程、执行流程、各阶段材料清单、常用时限速查 |
| 🏘 基层治理 | 宅基地、土地承包、邻里、赡养、彩礼返还、农民工欠薪、村务公开/信访、村委会证明等场景，填要素即生成文书 |
| ⚙️ 模型与费用 | 多模型切换：DeepSeek、智谱 GLM-4-Flash（免费）、通义千问、自定义接口；API 密钥本机保存；调用次数、tokens、估算费用台账；数据导出/导入备份 |

## 使用方法

1. 打开页面后，点右上角「⚙️」，选一个服务商并填入 API 密钥（DeepSeek 便宜；智谱 glm-4-flash 永久免费，余额不足时切换即可）。
2. 到「材料撰写」粘贴素材，选文书类型，点「AI 分析并生成」，核对后点「生成文书」。
3. 成稿可复制、导出 Word、打印，也可「存入案件档案」，下次从案件台打开继续。

## 数据与安全

- API 密钥、案件、费用台账都只存在本机浏览器（localStorage），不会上传到任何服务器。
- 可随时在「模型与费用」页导出 JSON 备份，换设备后导入即可恢复。
